ตั้งค่า Cloud Realtime (GitHub Pages)

ทำไมโฮสต์บน GitHub Pages ถึงต้องเปิด Cloud Realtime?
เพราะ GitHub Pages เป็นเว็บประเภท Static Web (ไม่มี Database ในตัว) ข้อมูลที่เพิ่มปกติจะบันทึกลงในเครื่องแอดมินเท่านั้น การเปิดใช้ Firebase Realtime Database (ฟรี 100%) จะทำให้เมื่อแอดมินพิมพ์ชื่อแล้วกดบันทึก ข้อมูลจะวิ่งไปอัปเดตหน้าเว็บของทุกคนทั่วโลกสดๆ ทันที ไม่ต้องรอรีเฟรช!
กำลังตรวจสอบสถานะ...
คัดลอกจาก Firebase Console > เมนู Realtime Database (URL ที่ขึ้นต้นด้วย https://)
วิธีสร้าง Firebase Realtime ฟรี 3 ขั้นตอน:
1. เข้า console.firebase.google.com แล้วกด "สร้างโปรเจกต์" (ฟรี ไม่ต้องผูกบัตร)
2. เมนูด้านซ้ายเลือก "Realtime Database" > กด "Create Database" > เลือก "Start in test mode"
3. นำ URL ที่ได้มาวางในช่องด้านบน หรือนำไปวางในไฟล์ firebase-config.js บน GitHub ได้เลย!
